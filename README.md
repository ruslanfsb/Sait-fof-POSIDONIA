# POSIDONIA — official website

Official website of **POSIDONIA**, a Cyprus-based startup researching sustainable materials made from responsibly sourced, beach-cast Mediterranean seagrass (*Posidonia oceanica*).

> From the Mediterranean. For a Sustainable Future.

Статический сайт: одна главная страница из 10 секций + страница Privacy Policy. Без бэкенда, без базы данных, без трекеров. Работает на любом статическом хостинге (GitHub Pages, Netlify, Vercel, обычный веб-хостинг).

## Стек

- **Vite 8 + TypeScript**, без фреймворка. Весь текст рендерится в HTML **на этапе сборки** из одного файла контента, поэтому страница быстрая и полностью видна поисковикам.
- Шрифты Manrope и IBM Plex Mono подключены локально (`@fontsource`), без запросов к Google.
- Графика — SVG и canvas, генерируются кодом (никаких стоковых фото).
- Проверки: `tsc`, ESLint, Playwright-тесты (десктоп 1440 px и мобильный 375 px).

## Команды

```bash
npm install          # установить зависимости
npm run dev          # локальный сервер разработки (http://localhost:5173)
npm run build        # сборка в папку dist/
npm run preview      # просмотр собранной версии
npm run check        # всё сразу: типы, линтер, сборка, тесты
npm run assets       # пересоздать favicon / OG-картинку из логотипа
```

Для тестов нужен Chromium для Playwright: `npx playwright install chromium` (один раз).

## Где что редактировать

| Что | Файл |
| --- | --- |
| **Весь текст сайта**, email, адрес сайта, соцсети, имена и фото основателей | `src/content/site.ts` |
| Логотип (временный знак-трезубец) | `src/render/brand.ts`, затем `npm run assets` |
| Цвета, шрифты, отступы | `src/styles/base.css` (токены в `:root`) |
| Разметка секций | `src/render/sections.ts` |
| Поведение (меню, анимации, форма) | `src/client/*.ts` |

### Что нужно заполнить перед публикацией

Все поля — в `src/content/site.ts`, объект `company`:

1. **`siteUrl`** — итоговый адрес сайта со слешем в конце, например `https://ruslanfsb.github.io/Sait-fof-POSIDONIA/` или ваш домен. Нужен для canonical, превью в соцсетях (og:image) и `sitemap.xml`.
2. **`email`** — публичный адрес для связи. Пока пусто, на сайте написано «To be published».
3. **Форма обратной связи** — один из вариантов:
   - только `email` → кнопка «Compose email» открывает почтовую программу посетителя с готовым письмом (сайт честно пишет, что письмо ещё не отправлено);
   - `formEndpoint` (например, Formspree: `https://formspree.io/f/xxxxxxx`) → форма отправляет сообщение напрямую и показывает реальный результат (успех/ошибка);
   - ничего не задано → форма видна, но кнопка неактивна с пояснением.
   Адрес Formspree — публичный, это не секрет. Ключи и токены в код не добавлять.
4. **`socials`** — ссылки на LinkedIn/Instagram. Пустые не отображаются.
5. **Основатели** — `team.founders[].name` и `photo` (квадратное фото положить в `public/team/…` и указать путь, например `team/ceo.jpg`). Пока пусто, показываются аккуратные карточки с монограммой роли.

## Деплой на GitHub Pages

В репозитории уже есть workflow `.github/workflows/deploy.yml`: при пуше в `main` он проверяет типы, линтер, гоняет тесты, собирает сайт и публикует папку `dist`.

Один раз в настройках репозитория: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

Сборка использует относительные пути (`base: './'`), поэтому сайт работает и в подпапке `/<repo>/`, и на собственном домене.

## Деплой на обычный хостинг

```bash
npm ci
npm run build
```

Загрузить **содержимое** папки `dist/` в корень сайта (или в любую подпапку) по FTP/панели хостинга.

## Принципы контента

Сайт намеренно не содержит выдуманных фактов: никаких показателей теплопроводности, сертификатов, наград, инвестиций, партнёров, мощностей или дат. Статусы продуктов — «In development» / «Future research». Единственное внешнее утверждение о законодательстве (луга *Posidonia* — приоритетное местообитание по Annex I Директивы ЕС о местообитаниях) сопровождается ссылкой на источник — Офис публикаций ЕС.
